Fonte: levantamento original da E1. Atenção: este dicionário é síntese documental; o arquivo docs/script.sql é a fonte executável definitiva para tamanhos, restrições compostas, FK e CHECK. Condições entre tabelas são auditadas por A01–A11 e necessitam de transações/validações na aplicação.
